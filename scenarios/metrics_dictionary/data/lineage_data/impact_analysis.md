# 数据血缘与影响分析（演示资料 v1）

适用日期为 2026-01-01 起。血缘是已维护的知识资料，本平台检索并解释这些关系，不自动扫描生产数据库或调度系统。

定位指标来源时，先用指标编码查询 lineage_catalog.csv，再使用来源表和来源字段查询数据字典。GMV、净支付金额、支付客单价均依赖 dwd_trade_order；支付转化率还依赖 dwd_user_visit。

如果 pay_amount 的单位、是否含运费或优惠处理方式变化，应检查 M001、M002、M004 及全站日交易看板。若 user_id 的生成规则发生变化，应检查 M003、M004 的用户去重与关联关系。若 pay_time 的时区变化，会影响所有四个指标的自然日归属。

影响分析只覆盖资料中登记的依赖。未登记的下游不能据此认定不受影响；需由数据开发确认实际依赖，再更新口径与血缘资料。
