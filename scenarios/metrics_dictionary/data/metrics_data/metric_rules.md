# 指标使用说明（演示资料）

本资料属于虚构企业的演示知识库，不代表任何实际企业已经批准的指标标准。责任部门为示例组织；口径版本 v1，自 2026-01-01 起适用。指标计算定义以同目录 metric_catalog.csv 为准。

## GMV、净支付金额和客单价

GMV（M001）统计支付成功订单的实付金额，不扣退款。支付成功包括当前状态为 PAID 或 REFUNDED 的订单，排除测试订单，按支付时间 pay_time 归属自然日，按 order_id 去重。实付金额单位为人民币元，不含运费，已扣优惠。不应把订单创建金额或净支付金额当作 GMV。

净支付金额（M002）使用支付日归属法：同一支付日订单的实付金额减去截至该日次日 08:00 的成功退款累计金额。退款先聚合到订单粒度，再与订单一对一关联，禁止直接关联退款明细导致订单金额倍增。超过该快照时点的退款不改写已发布快照；如需重算历史日期，应发布明确的重述版本。本示例不提供历史重述数据。

支付客单价（M004）为 GMV（M001）除以当日成功支付的去重用户数，按用户计算，不是按订单计算的平均订单金额。支付用户标识为空时属于质量异常，不能静默从分母丢弃后发布。

## 支付转化率

支付转化率（M003）的分母是当天登录访问的非测试去重用户；分子是这些用户中当天支付成功的用户，取访问用户与支付用户的交集。分子和分母都按 user_id 去重，不按访问次数或订单数计算。分母为零返回 NULL 并标记无访问样本，不能写成 0%。

所有自然日均采用 Asia/Shanghai 时区的左闭右开区间 [当日00:00, 次日00:00)。计算时间窗口、去重键和过滤条件必须一致。演示口径只支持全站日粒度，未提供渠道归因规则，不能自行生成按渠道转化率。

## 资料与计算边界

知识平台提供定义和来源解释，不提供实时指标查询或业务 SQL 执行。表结构、引擎方言、数据权限或业务日期不明确时，应先补充信息。指标字典不包含真实交易记录，无法据此回答某日实际销售额。
