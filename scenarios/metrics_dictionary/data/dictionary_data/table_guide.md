# 数据表使用说明（演示字典 v1）

适用日期为 2026-01-01 起。字段明细见 field_dictionary.csv。本资料仅描述演示逻辑表，没有部署这些表，也未绑定任何生产数据仓库。

dwd_trade_order 是订单粒度事实表，主键 order_id，一行一个订单。责任部门为交易数据组。金额类型为 DECIMAL(18,2)，pay_amount 为人民币元实付金额，不含运费、已扣优惠；refund_amount 为快照时点累计成功退款金额，无退款时取 0。

订单状态 CREATED 表示待支付，PAID 表示支付成功，CANCELLED 表示未支付取消，REFUNDED 表示全额退款；部分退款仍为 PAID。统计曾经支付成功订单时使用 PAID 和 REFUNDED，不能只选 PAID 而漏掉已全额退款订单。

dwd_user_visit 是访问事件粒度事实表，主键 event_id。责任部门为用户增长组。匿名访问的 user_id 为空，不进入登录访问用户分母。同一用户一天可能有多次访问；计算转化率必须先按 user_id 和自然日去重，避免连接订单表时扩大行数。

时间均以 Asia/Shanghai 解释。查询字段时应同时提供表名和字段名；同名 user_id 在多个表出现时需确认业务主体。真实企业接入时还应提供物理数据库、Schema、字段脱敏规则、更新时间和审批后的字典版本；本示例未提供这些信息，不应推测。
