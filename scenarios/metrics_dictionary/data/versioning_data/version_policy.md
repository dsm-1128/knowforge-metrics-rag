# 指标与数据字典版本管理（演示制度）

文档版本 v1，生效日期 2026-01-01。责任部门：数据管理团队。本制度为演示资料。

## 版本变更流程

指标负责人提交变更原因、指标编码、原公式、新公式、统计粒度、过滤条件、去重键、单位和拟生效时间。字段变更还须提供完整表名、字段名、类型与枚举差异。数据开发核对上游字段和下游影响，业务负责人审核含义，数据管理团队审核命名、版本和适用范围。完成审核后发布新业务版本，保留旧版本与其失效时间。

本平台的知识库版本管理用于资料入库、校验和切换；上述业务审批应由责任部门完成，本平台不声称已实现业务审批工单。

## 业务日期与版本选择

口径生效区间采用开始日期包含、结束日期不包含的规则。按被问及的业务日期、组织和适用范围选择口径，不能按文档上传日期代替生效日期。未指定日期且存在多个适用口径时，先询问业务日期。检索排名靠前不等于口径最新。

演示数据仅发布 v1，自 2026-01-01 起适用，未提供 v2 或更早版本。对 2025 年或旧口径的询问应回答信息不足，不能推测历史版本。

## 口径冲突

两个来源对同名指标给出不同定义时，分别列出来源、版本、适用范围及公式差异，交由指标负责人确认。不能把订单数分母与用户数分母拼接为统一客单价。

知识库 kb_version 是检索索引的构建版本；业务版本 v1 是指标定义的版本，两者不能互相替代。发布资料时应同步更新指标字典、字段字典、FAQ 和测试案例，再运行入库质量检查，验证后激活知识库版本。
